# Добавка

Мессенджер **Добавка**, by Zvizdesc.

[Скачать последнюю версию для Windows](https://github.com/Zvizdesc/Dobavka-releases/releases/latest)

В этом репозитории размещаются только установщики и файлы автоматического обновления. Исходный код приложения не публикуется.

После установки версии 1.15.0 или новее приложение проверяет обновления при запуске. Если новая версия доступна, она загружается и устанавливается автоматически. При недоступном GitHub приложение запускается как обычно.
